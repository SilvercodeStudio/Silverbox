How it works

Set up once, then play.

Silverbox runs eXo's setup itself, so you don't need a Windows PC. A collection already set up on Windows works too.

  1. 1

    Download an eXo collection

    Get the torrent for eXoDOS or another pack from retro-exo.com, and open it in a BitTorrent client such as qBittorrent or Transmission. The larger packs take a while: the full eXoDOS is about 700 GB. eXoDOS Lite is about 6 GB, because it leaves out the games; Silverbox downloads each one when you install it.

  2. 2

    Add it to Silverbox

    Drag the folder onto the window. Silverbox asks whether to unpack into the download itself, as on Windows, or into a separate local folder that leaves the download as it came.

  3. 3

    Install the emulators

    DOSBox Staging for most eXoDOS games, and the others for the packs you have. Silverbox shows which ones it found, and notices one you install while it is open.

  4. 4

    Pick a game

    Press Play. The first time, Silverbox installs the game from its archive in the background, downloading it first from a Lite collection. Then it starts the emulator eXo chose for that game, with a config translated from eXo's launch script.

Launching

The right DOSBox for every game.

eXoDOS picks a DOSBox build per game: 0.74, ECE, Staging, SVN Daum or DOSBox-X. Silverbox matches each to a Mac build, sending Daum and DOSBox-X games to DOSBox-X and everything else to DOSBox Staging, and translates the game's config from eXo's Windows launch script.

Want something different? Change the emulator for any game in its info sheet, or edit a copy of its config. Changes are kept in the local data folder; the eXo files are not changed.

Sound and picture

The music the games were written for.

Games set up for the Roland MT-32 use MT-32 emulation with the ROMs that come with eXo. General MIDI plays through FluidSynth and the eXoDOS Sound Canvas SoundFont, as on Windows; DOSBox-X and DOSBox Staging 0.83 or later have FluidSynth built in. Where eXo's in-game sound menus pick General MIDI, Silverbox sends them to the same synthesizer.

FluidSynth ready in DOSBox Staging General MIDI games play with the eXoDOS Sound Canvas SoundFont.

The picture can stay as each game was configured, or take a CRT shader in DOSBox Staging. Start in full screen, and skip the emulator's start-up banner.

The library

More than the games.

A full set of eXo collections holds thousands of games, and the books, magazines and music that came with them. Silverbox keeps all of it easy to look through.

Soundtracks

Play the eXoDOS game soundtracks as albums inside the app, and start from the track you want.

Menu music

Where eXo supplies it, each game's music plays as you browse, tracker modules included. Turn it off any time.

Manuals, magazines and books

Read what eXo collected alongside the games, from hint books to old computer magazines.

Search as you type

One search covers every pack at once, and narrows the library with each letter. Other Versions finds the same game in your other packs.

Box art or a list

Browse by cover in a grid you can size, or as a list you can sort.

Your favorites, and eXo's

Keep your own favorites, or start with the games the eXo team marked as eXo Favorites.

Play history

Installed and Recently Played, with when you last played each game, for how long, and how often.

Keyboard and controller

Browse the whole library from the keyboard, or from the couch with a PlayStation, Xbox or MFi controller, manuals and maps included.

Read-only is fine

Keep the collection on another drive or a NAS, even one a Windows PC shares. Installs, saves and caches go to a local data folder.

Emulators

The emulators do the hard part.

Games run in Mac emulators that you install yourself, each made by its own team. Put them in Applications, or choose them in Settings. Silverbox starts every game in the one eXo chose for it, with eXo's settings for that game.

eXo ships Windows builds of the same emulators; Silverbox doesn't use them. And you need none of them just to browse.

Beyond eXo

Your LaunchBox library, too.

Underneath, the eXo collections are LaunchBox libraries, so Silverbox reads others as well. Point it at a LaunchBox folder from Windows and your console, computer and arcade games join the list, with the metadata and media LaunchBox already gathered. Launching them in RetroArch, Dolphin, MAME and Mednafen is experimental.

Silverbox doesn't scan ROMs or fetch art itself; building the library is LaunchBox's job. Silverbox isn't affiliated with LaunchBox.

Questions

Frequently asked

Is this an official eXo project?

No. Silverbox is an independent app, not affiliated with or endorsed by the eXo project. The collections are made by the eXo team; Silverbox only reads them.

Does Silverbox come with any games?

No. It includes no games, media or emulators. Download the eXo collections from retro-exo.com and the emulators from their own sites.

Do I need a Windows PC?

No. Silverbox runs eXo's setup itself. A collection that was set up on Windows works too.

Will it change my eXo folder?

Only if you ask it to. By default, installed games, save backups, edited configs and caches go to a local data folder, and the eXo folder can be read-only. Setting up inside the download, or installing games in place as eXo does on Windows, are choices you make. eXoDOS Lite games download into the set-up collection: into the eXo folder only if you set it up in place, otherwise into the local copy.

What about eXoDOS Lite?

Lite leaves out the games and downloads each one when you install it. Silverbox does the same, from the eXoDOS torrent that Lite includes, with aria2 (brew install aria2). The first download can take a minute or so to find other computers sharing the torrent; later ones start in seconds.

Can I share a collection with a Windows PC?

Yes. Keep it on a NAS or network share both can reach. Don't open the same folder on both at once unless the Mac unpacks into its own local folder.

Can I use it for consoles?

With a LaunchBox library, you can browse them now; launching them is experimental. Silverbox uses the metadata and media LaunchBox has already registered; it doesn't discover or scrape games on its own.

Is it related to LaunchBox?

No. The eXo collections come set up for LaunchBox, a Windows front-end, so Silverbox reads its library format. LaunchBox is a separate product by its own developers.

What does it need?

macOS 15 or later on Apple silicon or Intel, one or more eXo downloads, and the emulators for the packs you play.

Does it need an account, or send anything about me?

No account, and nothing about you is sent. Silverbox reads your collections and starts the emulators on your Mac. Its only network use is downloading a game that an eXoDOS Lite collection leaves out, over BitTorrent, when you ask. See Privacy.

Who makes it?

One software engineer with decades of industry experience and an interest in preserving classic games and media. It was built with extensive help from AI coding tools, under his close direction.

What does it cost?

Nothing. Silverbox is free, and its code is open source under the MIT License on GitHub. The name and the icon stay with the author.
