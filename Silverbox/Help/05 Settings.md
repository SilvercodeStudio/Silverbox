# Settings

Open Settings with Command-Comma.

## General

- **App icon** — amber or green. The Dock and the About window show the chosen icon, and the app uses its colour for highlights. Only the amber icon follows the icon style chosen in System Settings › Appearance (dark, clear or tinted).
- **Appearance** — light, dark, or matching the system.
- **Menu music** — on or off, its volume, and whether it keeps playing when another app is in front.
- **Videos** — the app that plays videos: the macOS default for MP4 files, unless you choose one.
- **Playing** — whether to show the launch options dialog before each game.
- **Library view** — whether hidden games appear in the library.
- **Game controller** — the controllers Silverbox sees.

## Library

Each collection, with its name, its folder, whether it is on, what was found in it and its path substitutions; Add Collection…, Remove and Rescan All. Then the local data folder and where new games are installed. See Collections and the local data folder.

## Emulators

Where each emulator is installed, with its status, or a link to get it when it is missing. You can choose the app or the program inside it. Silverbox notices an emulator you install while this tab is open.

- **DOSBox Staging and DOSBox-X**, and which one to use by default: the build eXo picks for each game, or always one of them. DOSBox Staging also shows whether it can use FluidSynth.
- **86Box**, for the eXoWin9x games that need it.
- **ScummVM**, and a ScummVM daily build for the games that need it.
- **Spatterlight**, for eXoIF.
- **RetroArch** (with its cores folder), **Dolphin**, **MAME** and **Mednafen**, for console, computer and arcade platforms, and a list of those platforms with the emulator and core each one uses.

## Display & Sound

The defaults for every launch: full screen or window, window size, aspect ratio correction, CRT shader (DOSBox Staging), graphics filter (DOSBox-X), the start-up banner, and how to play General MIDI music. The launch options dialog starts from these values. Under General MIDI, a line says whether your DOSBox Staging can use FluidSynth; it updates by itself if you install FluidSynth or a newer DOSBox Staging while Settings is open.
