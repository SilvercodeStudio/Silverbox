# Keyboard and Controller

The library can be browsed without the mouse. Click a game once, or press Tab until the grid has focus, then use the keys below. The list view uses the same keys. Help › Keyboard Shortcuts (Command-/) shows this table in a small window that Escape closes.

## Keyboard

| Key | Action |
|---|---|
| Arrow keys | Move between games |
| Home, End | First or last game |
| Page Up, Page Down | Jump four rows |
| Return | Play the game, or Install when it is not installed yet |
| Control-Return | Open the selected game's context menu, as a right-click does |
| Space | Quick Look the image or video shown in the inspector |
| Option-Left, Option-Right | Previous or next image |
| Command-Y | Quick Look the current image or video |
| Command-Shift-Y | Quick Look the manual |
| Command-Option-Y | Quick Look the extras (maps, clue books, reference cards) |
| Command-Down, Command-Up | Open the game page, back to the library |
| Command-F | Search games |
| Command-Return | Play |
| Command-Shift-Return | Configure… |
| Command-D | Add to or remove from Favorites |
| Command-I | Edit game info |
| Command-Delete | Uninstall… (asks first) |
| Command-Plus, Command-Minus, Command-0 | Larger, smaller or default tiles |
| Command-1, Command-2 | Show as grid or list |
| Command-Option-I | Show or hide the inspector |
| Command-Shift-P | Pause or play the menu music, or the album |
| Command-Option-Left, Command-Option-Right | Previous or next album track |
| Command-. | Stop the album |
| Escape | Close the Quick Look panel or the game page, or clear the search |
| Command-/ | Keyboard Shortcuts window |

The Quick Look panel pages through everything the game has: its images and videos, then the manual, then the extras. Use the arrow keys inside the panel; Space or Escape closes it. Clicking an extra in the inspector opens the same panel at that item.

## Game controller

Pair a controller in System Settings › Bluetooth. PlayStation, Xbox and MFi controllers work, and Settings › General lists the controllers Silverbox sees. The controller drives Silverbox only while it is the front app; once a game is running, the emulator has the controller.

| Control (PlayStation / Xbox) | Action |
|---|---|
| D-pad or left stick | Move between games; hold to keep moving |
| Cross / A | Play, or press the default button of a dialog |
| Circle / B | Back: close the panel, the page or the dialog, or clear the search |
| Square / X | Quick Look the current image or video |
| Triangle / Y | Open the game page, or come back from it |
| L1, R1 / LB, RB | Previous or next image |
| L2, R2 / LT, RT | Page up or down |
| Options / Menu | Configure… |
| Create / View | Add to or remove from Favorites |

The controller sends the same commands as the keyboard, so everything in the keyboard table applies to it too. To read a manual or a map from the couch: Square opens Quick Look on the current image, then the D-pad pages on through the manual and the extras, and Circle closes the panel.
