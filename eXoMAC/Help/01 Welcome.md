# Welcome to Silverbox

Silverbox is a front-end for the eXoDOS and eXoWin9x game preservation collections. It reads an existing collection, shows the games with their box art, manuals and extras, and launches them in a DOSBox emulator with a configuration translated from the collection's Windows launch scripts.

The games, media and emulators are not part of Silverbox. You need:

- An eXo collection: an eXoDOS download as it came (Silverbox sets it up, as eXo's setup does on Windows), or a collection already set up. The other eXo packs and LaunchBox libraries work too.
- DOSBox Staging for eXoDOS games, and DOSBox-X for eXoWin9x games and the eXoDOS games made for it.
- For the other packs: 86Box (about thirty eXoWin9x games), ScummVM (eXoScummVM), Spatterlight (eXoIF) and RetroArch (eXoIF's 8-bit versions, and consoles).

Until you add a collection, the window shows these two steps, with each emulator found or a link to get it. Emulators you install while Silverbox is open show up without a restart.

This is an early version. Expect rough edges, and please report what you find.
